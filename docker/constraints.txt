# Myink Python 依赖锁：整棵依赖树（含间接依赖）的**精确版本**，由 Dockerfile 用 `-c` 生效。
#
# 为什么要有它：pyproject.toml 里写的是 `>=` 区间（那是给人读的意图，不是可复现的构建）。
# 没有约束文件时，同一份代码在三个月后重新 build 会拉到另一批版本——排查线上问题时
# 「跑的是哪一版 langgraph」这种问题将无法回答。这里把答案钉死在仓库里。
#
# 重新生成（改了 pyproject 的依赖之后必须做，否则新依赖不受约束）：
#   docker compose build myink-api
#   docker run --rm --entrypoint sh myink-api:local -c 'pip freeze --exclude-editable' \
#     | grep -v '^myink' | sort > docker/constraints.txt
#   然后手工把本段注释贴回文件头（上面的命令会覆盖掉它）。
#
# 注意：这里只有核心依赖。开了向量能力（pip install .[ml]，装 torch/sentence-transformers
# ~2GB）之后，那批包不在本文件中——需要时在装了 ml extras 的镜像里重新生成一次。
