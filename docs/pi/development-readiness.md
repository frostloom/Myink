# 本机 Pi 开发验收维护

本机使用 MyinkPiLab（WSL2）和现有模型接口。开发任务由宿主冻结范围、候选、检查与费用，Pi 通过受控工具修改候选。Git 提交推送由宿主在检查和审查后执行。最新结果见 [040 真实开发回放](../evaluations/pi-local-trial/development-runtime040-2026-10-18.md)：真实补丁、检查、最终状态及清理已认证；候选因当前代码已有修复且额外序列化开销未被采纳。此前 [付费前验收记录](../evaluations/pi-development-readiness-2026-10-18.md) 保留为历史。

## 完成协议

一次开发只有同时满足以下条件才可完成：

1. Pi 实际调用 `apply_patch`，产生范围内的非空改动。
2. 最后一次修改之后，`run_check` 的 `unit` 检查实际通过，绑定当前候选、计划、版本和源码摘要。
3. 检查之后 Pi 调用 `candidate_status({})`；ID、base、generation、候选哈希一致，未发布，并列出上述成功检查的回执。
4. 宿主在 Pi 所属进程树退出后，认证会话、全部工具记录、检查和最终状态。再次修改会使先前检查与状态失效。

最终文字、agent 结束事件或宿主代调状态均不能替代该协议。失败反馈只能指导预算内修复，不能批准候选。

## 运行和费用边界

本轮用户授权新增模型费用最多 5 元；原 `local-trial-1` 的累计账本和 20 元上限保留。新轮费用按初始账本检查点的增量计算，未知用量保留预留，不清零历史。每次预留前的本轮检查必须位于覆盖预留、发送、完整响应及结算的同一工作锁内；发送前再次核对。只在锁外检查会让并发请求借用同一余额。

当前冻结配置按每次最多 1,000,000 输入及 2,048 输出 token、输入/缓存写入 2 元和输出 8 元每百万 token，预留最多 2,016,384 微元。费用是保守估算及预留，并非服务商账单。发送前核对现有接口、当前价格与配置，不因历史报告自动获得新预算。价格出处为[现有提供方模型页](https://www.qianwenai.com/models/deepseek-v4.1-flash)；本轮沿用较高冻结费率。

每次新运行创建新身份，重新测量检查器与 Pi 隔离、固定运行时、受控工具、超时/溢出及所属进程树清理。旧成功证明、过期 epoch、失败会话不能复用为新执行许可。检查器实际执行候选代码；宿主不能直接导入候选文件。Pi 网络允许 loopback，不能称为内核逐端口隔离。

## 维护操作

现有原生运行材料留在 E 盘的私有实验环境，公开记录仅保留摘要。准备、协议模拟与真实模型调用分开；缺少外发授权时可以完成离线工作，不能发送。运行前确认具体目的地以及允许发送的源码/任务内容，不发送凭据或真实用户数据。

不要重放单次运行命令。新任务需要新候选身份、最新累计检查点、明确的变更范围与固定检查、独立审查和新的宿主授权记录。一次 capture 合成修复通过只能证明该受控开发流程；其他任务类型、业务完整服务、语义质量与线上自动迭代分别验收。
