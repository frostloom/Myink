# 管理后台与会员模型分配改版

用户反馈上一版会员区分不足、后台导航层级不清、模型分配页不够整齐，并明确批准直接按四组导航和普通/VIP并排对照的方向修改。

## 结果

- 导航分为运营概览、用户与会员、模型与策略、写作资源；增加统一线性图标、分组标题与当前位置强调。概览与账号详情均保持唯一当前位置，账号安全和管理员权限门禁保留。
- 模型分配改为一张按创作环节排列的普通/VIP对照表。普通选择器排除 VIP 专用模型；VIP可沿用普通环节分配、跟随VIP写作默认，或单独指定。显示值按后端有效默认路由规则推导。
- 明确写为“默认模型预览，保存后生效”，避免把草稿当成实际运行模型；个人选择仍受会员权限限制。
- 就绪检查折叠为状态条，任务调度独立成区，展示权重与份额预览。零值、非整数和超范围权重在前端阻止提交。
- 模型卡片、用户列表和账号详情使用统一会员徽标；VIP填充、普通轮廓，区分会员与管理员角色。
- 手机端保留同环节对照，导航改为可展开的分组菜单；选择页面后关闭，Esc关闭时焦点回到菜单按钮。
