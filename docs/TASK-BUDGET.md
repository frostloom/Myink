# 任务总预算：使用与维护

每个新 Agent 任务把账号“全局环境配置 → 任务总预算”保存为独立快照。默认 100 次实际模型请求、5 元估算费用、1800 秒有效运行时间；每个维度的 0 表示不限。修改默认值不改变既有任务。批次的规划、各章、修订、摘要与复盘共用根任务预算。

## 用户操作

预算不足时任务显示“预算暂停”，已生成的结果和执行位置保留。任务详情可追加请求次数、费用或运行分钟，然后继续。追加增加上限，累计消耗不归零。普通人工暂停仍使用原有续跑操作。旧任务没有预算快照，保持原有行为。

费用是准入估算，不是供应商账单。每次 HTTP 请求前预留输入和最大输出费用；未知模型使用正数保守预留。失败、断流或缺失可信用量时，预留不自动退还，因此页面会单独显示“未确认预留”。如需继续，追加额度；不要直接删除账本来“退款”。队列和暂停等待不计运行时间。

## API 与幂等

- GET /api/v1/environment、PUT /api/v1/environment：task_budget 包含 max_requests、max_cost_yuan、max_runtime_seconds。部分更新保留其他环境配置。
- GET /api/v1/tasks/{id} 和任务历史：budget 返回快照、已用请求/费用/时间、预留费用、暂停原因、阶段和版本；旧任务为 null。
- POST /api/v1/tasks/{id}/resume：追加体含 operation_id(UUID)、add_requests、add_cost_yuan、add_runtime_seconds。正数追加必须有操作 ID。相同 ID、相同参数只追加一次；相同 ID、不同参数返回 409。

没有余量的任务不能通过空体续跑绕过预算。终态、他人任务和仍有有效运行租约的任务不能追加。0 上限表示不限，追加不会把不限变成有限。

续跑发布使用独立、有界、mandatory 的 RabbitMQ confirm。明确 nack/不可路由可用原操作 ID 重试，额度不会再次追加。确认超时记为 uncertain：任务保持 queued，不退额度、不自动重发原操作。先刷新；确实没有推进时，可使用新操作 ID 和全 0 追加重新投递，旧投递由 Worker 操作身份校验拦截。

## 数据与恢复

- task_budgets：一个根任务一行，保存所有者、限额、请求数、整数微元费用、运行毫秒、执行租约、阶段和版本。
- task_budget_attempts：每次实际 HTTP 尝试独立预留/结算。重试和 fallback 都算请求。
- task_budget_calls：模型/读取工具成果、短篇阶段进度、落库副作用收据和预算追加操作收据。

账本事务独立于章节业务事务，正文回滚不能返还实际请求。行锁只包短事务，不在网络请求期间持有。执行租约 60 秒、20 秒心跳；失去租约的 Worker 不得继续请求或覆盖新所有者状态。崩溃后的有效运行时间最多累计到租约截止，租约后的停机等待不收费。

调用身份包含根任务、节点/章号、修订/重规划轮次和节点内位置；输入摘要覆盖消息、工具、模型链、端点、价格和生成参数。相同输入恢复使用已保存成果。供应商缓存明细不足以可靠拆分时，预算按较高输入价结算；Anthropic 缓存创建/读取价格不完整时保留预留。输入用量存在但输出用量缺失也不释放预留。受管理 Anthropic 流缺少 message_stop 视为失败，不能缓存成成功成果。

总运行 deadline 约束网络结果等待和流块读取，避免缓慢传输绕过单次 read timeout。超时后主任务停止，不再结算或使用迟到结果；已送达供应商的请求无法撤销，后台传输可能继续到连接超时/返回，预留仍保留。

成功 HTTP 返回到成果落库之间仍存在崩溃窗口：供应商没有幂等请求接口时，无法保证绝对零重复付费；保留预留并计入每次新尝试。章节落库与副作用收据同事务，避免已提交数据库但图检查点未提交时重复写入。

长篇依赖 LangGraph PostgreSQL 检查点；短篇使用持久阶段成果，跳过已完成写作/审稿等阶段。手动取消优先于预算暂停。预算异常必须穿透摘要、复盘、fallback 和批次兜底，不自动重试。

## 升级与运维

数据库初始化是增量、幂等操作：先备份 PostgreSQL，再执行 myink init；重复执行不会重置预算。三张表使用项目 RLS，与任务/作品删除级联。旧任务没有快照时不补造预算。

每日账号额度仍独立生效。受管理任务通过 Redis rate:taskcost:{task_id} 记已计入每日额度的累计差值，暂停/恢复不会重复扣同一费用。该收据不设 TTL；仅在任务不再可能恢复、不会重投且已清理对应历史后清理，不能在运行/暂停期间删除，否则可能重复计入每日额度。模型成果可能含正文，按项目权限和任务保留周期维护，不公开复制生产内容。

部署必须同步 API、所有 Worker 和前端，不能让旧 Worker 消费新预算任务。保留模型 .env 配置和数据卷；回滚镜像时保留新增表与账本，避免混用旧消费者处理受管理任务。

## 验证入口

Python 的 test_task_budget*.py 覆盖数据库、Provider、真实图恢复与 API 幂等；前端 TaskBudgetPanel/EnvironmentPage 测试覆盖操作身份及配置保存。完整隔离检查参见 scripts/ci-local.sh 与 .github/workflows/ci.yml。生产验证仅使用专用测试账号和合成素材，不重放用户历史。
