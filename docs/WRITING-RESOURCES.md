# 写作资源与生效时机

管理员在“写作资源”统一管理三类平台内容。作品的私有设定仍由作者维护，不会同步到平台。

## 自动角色提示词

对应环节执行时自动使用，无需用户在作品中选用。创作要求与角色共用补充可保存草稿、发布和回退；未发布的编辑不影响创作。新任务捕获当前发布版本及旧平台补充，进行中的任务和重试继续使用受理快照。

| 角色 | 覆盖环节 |
| --- | --- |
| 写作 | 长篇正文、全文修订、局部修订；短篇整篇、改稿、缺章补写 |
| 规划 | 建书对话、人物出场、整书大纲、章节规划、批次规划、短篇方案和审纲；建书设定八种题材能力组合 |
| 审核 | 长篇单章审核、跨章复盘、卷级审计、短篇整篇审稿 |
| 记忆整理 | 章节人物与事件抽取、作者样本文风提炼 |
| 章节摘要 | 章节落库后的前情整理 |
| 设定一致性检查 | 正文与人物、关系及世界设定台账的语义比对 |

共 21 个静态阶段模板和 8 个建书设定变体。输出 JSON、正文/补丁标记、工具及路由协议由代码保留，不接受平台覆盖；格式纠错、工具结束提示和预算提示也属于固定流程，不作为可选写作素材。

旧角色发布缺少新阶段时，该阶段回退系统默认，不覆盖管理员已有草稿和发布。角色共用补充字段缺失时兼容受理时捕获的旧平台补充；显式留空表示停止追加。旧平台补充的迁移副本不再作为新的用户选用项展示，已有作品快照仍保留；相同追加文字在实际模型调用前去重。

## 作品选用的资源

| 资源 | 生效条件与用途 |
| --- | --- |
| 37 类题材包 | 作品选择后用于设定、规划、写作与审核；首个主题材占七成，其他辅题材合计三成 |
| 6 类题材精调规则 | 作品选用且匹配所选题材后，在填写的规划、写作或审核环节追加 |

| 章节衔接、收尾与表达规则 | 作品选用后，在各自填写的环节生效；相应创作检查随所选规则使用 |


## 建书题材目录与历史快照

新建书向导的 37 类题材目录与后台题材资源共用已发布内容。保存草稿不改变既有发布；
下架后目录不再提供该题材，过期的建书选择会收到重新选择提示。发布新名称也适用于短篇对话卡；
已下架的发布名称不会被静默当成自由题材。真正的自定义题材仍可使用。

建书时一次读取主辅题材，保存实际内容、能力开关及资源 ID、版本、发布代次；
后台之后发布或回退不会重写已有作品的题材快照。长篇幂等重试与短篇方案失败后的重试
继续使用已落库的作品及快照。尚未初始化写作资源的安装沿用旧题材配置。

作品是否启用可选写作资源仍由用户保存的选择决定，建书不会自动勾选或取消其他写作规则。
平台更新提醒继续针对已保存的作品资源选择；建书历史题材快照不会自动升级。

## 写作知识库：AI 按需查阅

人物设计、关系互动、桥段、命名、场景与节奏资料是通用写作方法，不要求作者逐份选用。平台发布的创作资料自动加入新任务的可查阅目录；任务只保存资源版本指针，工具按冻结版本读取需要的段落，不把整个资料库放入提示词。管理员发布或回退后，新任务采用该发布版本；进行中的任务和重试继续使用旧版本。下架资料不再进入新任务。

实际查阅由模型发出 `read_genre_reference` 工具请求，系统执行只读查询，再把返回内容交回同一次创作。人物动机与关系、桥段、题材机制、爽点节奏、命名和故事结构的设计或判断，会在提示中要求先查相关资料；已有足够依据的局部文字修订可以不查，不承诺每次生成都调用工具。

查阅已接入建书对话、设定与大纲、短篇方案和审纲、长篇人物出场及章节规划、批次规划、长短篇写作与修订、审核与复盘。规划、建书和短篇只获得资料查阅工具，不因此获得长篇人物台账等其他工具权限。每环节遵守 `MAX_TOOL_CALLS`（默认执行三次工具）；工具循环中的每次模型请求都经过原有准入或任务预算。工具额度用尽后，系统将已查结果汇总给最终生成轮，显式关闭工具；若上游仍返回工具请求，则作为协议错误处理，不能把“我再查一下”的过程说明交成正文。

运行记录 `agent_runs.detail.tool_trace` 保留实际工具、参数和结果摘要，能区分“给了工具但模型未查”和“确实读取过资料”。工具定义本身也计入账号级调用的预算预留。

“人物设计与关系写法”讲人物动机、行为逻辑与互动方式，不是本书的人物名单或实际关系；后者来自作品设定与台账。已有作品选择的参考快照及私有参考继续保留，并优先于平台同路径资料。个人资料不会同步到管理平台。

部分旧文件名与界面名称对应如下：

| 原文件名 | 中文名称与用途 |
| --- | --- |
| strand-weave-pattern | 多条剧情线交织写法：组织并行主线与支线 |
| plot-signal-vs-spoiler | 剧情铺垫与剧透的区别：埋线索时保留悬念 |
| reading-power-taxonomy | 追读动力与情绪回报：设计继续阅读的期待 |
| cool-points-guide | 爽点设计与兑现：安排情绪回报 |
| golden-finger-templates | 金手指设计参考：设计特殊能力及限制 |
| genre-profiles | 各类题材的写法与节奏：理解题材惯例 |

webnovel-writer 原始写作素材保留来源与许可。LICENSE、README、内部错误目录、工具术语对照、存储 schema 和资料加载索引不再展示为创作卡片；许可仍可展开查看。资料原路径等标识留在数据层，编辑正文不会重命名已有工具引用。

平台发布更新后，已有作品保持自己的资源快照，由作者确认升级；个人覆盖内容不被覆盖。未配置资源的旧作品沿用原有默认题材、精调与表达规则，不会因新界面而突然禁用。

## 作品自有上下文

作者文风档案、样本摘录、人物状态、世界观约束、历史正文、伏笔与剧情线、书籍大纲、章节计划、复盘经验，在相应创作阶段通过上下文召回或只读工具使用。这些是作品内容，不是平台公共资源，后台资源发布不会将其收录为公共素材。

## 运营数据与界面

运营概览与数据分析支持近 7 天、30 天及自定义 1 至 90 天的真实按日趋势，统一使用 UTC 自然日，空日期补零。数量、输入/输出 Token 和人民币估算费用分别画图，汇总与当前日期区间一致。原始用户、作品、任务与章节明细继续可下钻。

后台页面使用一个纵向滚动面；弹窗打开时冻结背景，长文本自动增高，预览不另设滚动窗口。窄屏表格允许必要的横向滚动。
