# 公网部署前检查（2026-09-19）

## 当前结论

密码认证与用户数据隔离已实现并完成回归，但**当前 Compose 仅适合本机验收，不能直接开放公网**。本次启动的网页入口为 `http://localhost`（Caddy 边缘层）。Python API 未发布宿主机端口；Caddy 是唯一发布端口的服务，且按设计监听所有网卡的 80/443，本机跑演示时对同局域网可达。以下未完成项不是已实现的安全保证。

网站已实现独立的 `role=user/admin` 与只读管理面板；`tier=normal/vip` 仍只是写作优先级，不是管理权限。管理员功能和本次账号切换验收见 [管理面板说明](ADMIN.md) 与 [管理员验收记录](ADMIN-ACCEPTANCE-2026-09-19.md)。服务器管理员通过 `docker compose exec myink-api myink reset-password <用户名>` 重设密码；不能把 RabbitMQ/数据库管理凭据当成网站登录账号。

## 已有防护

- 密码：随机盐 scrypt，N=131072、r=8、p=1；新密码为8–128字符，包含ASCII字母和数字，不强制大小写或符号；不保存明文。
- 认证：JWT 签名、签发方、到期和会话版本校验；改密/成功退出撤销该账号全部会话。默认/短签名密钥拒绝服务。
- 限制：认证请求最多 4096 字节；注册/登录/改密共享客户端来源地址每分钟 20 次（地址取自 Caddy 覆盖写入的 `X-Myink-Client-IP`，客户端伪造同名头无效）；API 每进程最多两个密码计算；基础设施故障时拒绝认证。
- 隔离：Python 自验 JWT 身份、项目归属检查、PostgreSQL FORCE RLS 和事务租户上下文；任务控制、入队、worker 及 SSE 都检查归属。用户不能通过更换项目 ID 或伪造用户头读取其他账号作品。
- 浏览器：账号切换卸载旧页面，关闭旧 SSE；拒绝旧请求/旧令牌响应；写作缓存按用户隔离。
- 流式会话：JWT 到期停止发送；已打开 SSE 每 15 秒重新验证会话，验证超时 5 秒，不承诺零延迟撤销。

现有 scrypt 参数与 [OWASP 密码存储指引](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) 列出的参数组合一致。

## 上线阻断项

| 项目 | 当前情况 | 上线前要求 |
|---|---|---|
| 公网入口 | Caddy 边缘层已就位（80/443、前端静态托管、按路径分流、SSE 无缓冲中继）；本地默认纯 HTTP，Compose 强制 APP_ENV=dev | 填真实域名走 ACME 自动签发续期；公网只开放 443（80 仅跳转/证书验证）；配置 HSTS 与安全响应头；Caddy 之前再加 CDN/云 LB 时必须配全局 trusted_proxies |
| 内部服务 | Python API 只在容器网络内监听（`expose`）；它自己验 JWT，不读内部用户头；DB/Redis/RabbitMQ 绑定本机 | 不发布内部服务端口；隔离内部网络，限制 Caddy/API/worker 的访问关系；禁止绕过 Caddy 直连 Python——那会同时绕过 TLS 与限流 |
| 浏览器令牌 | JWT 存于 localStorage，能被同源 JavaScript 读取 | 设计 HttpOnly + Secure + SameSite 的会话 Cookie，并配套 CSRF 防护；落实 CSP、XSS 防护及第三方依赖审查 |
| 自定义模型/MCP 地址 | 出站地址守卫已统一到「探针 + 保存」两条路径，且只放行全球可路由地址（阻断云元数据 169.254.169.254 与阿里云 100.100.100.200；本部署不使用本地模型，内网与回环一并拒绝）。未处理重定向跟随、DNS 重绑定与出站代理 | 全部出站路径统一 SSRF 防护：阻断私网、回环、链路本地和元数据服务；处理 DNS 重绑定、重定向和 IPv6；优先允许列表/受控出站代理；本地模型须由管理员显式授权 |
| 密钥与基础设施凭据 | JWT 已随机化；MODEL_CREDENTIAL_KEY 已换成独立随机主密钥，存量模型密文**已于 2026-09-20 迁移并验证**（见下「历史问题追平」）；DB/RabbitMQ 仍有本地默认凭据，Redis 未启用认证 | 备份后用独立随机主密钥事务式重加密存量模型凭据并验证；轮换基础设施密码；启用 Redis ACL/认证；使用 Secrets 管理，不把密钥写入镜像/日志 |
| 数据库权限 | 业务连接为 NOBYPASSRLS；API/worker 环境仍持有迁移管理员连接配置 | 将迁移放入独立作业；运行时去掉超级用户凭据；按需要收紧账号/模型凭据表权限；数据库管理员不属于 RLS 能防御的攻击者 |
| 防撞库和滥用 | 认证限流按 Caddy 覆盖写入的 `X-Myink-Client-IP` 分桶，客户端伪造同名头无效。仅按 IP 分桶，无账号维度 | Caddy 之前再加 CDN/云 LB 时必须配 Caddy 全局 `trusted_proxies` 并把取值换成 `{client_ip}`，否则所有用户塌进同一个桶、一人刷即锁死全员登录；再按真实客户端 IP + 账号组合限流，增加退避/验证码/告警；限制注册和写作成本滥用，必要时邀请注册 |
| 运维与版本 | 已有测试，无生产安全/容量验收 | 固定和扫描依赖/镜像版本；非 root 容器、资源限制、监控告警、日志脱敏；离机加密备份及恢复演练；公网环境再做越权、SSRF、XSS和负载测试 |
| 管理后台 | 已有显式角色校验、跨用户只读管理及访问审计；尚无MFA，报表复用管理数据库连接 | 上线前启用MFA、专用最小权限报表角色、审计留存及告警；不要将只读应用接口等同于数据库凭据最小权限 |

localStorage 中的会话令牌会扩大 XSS 的影响；[OWASP HTML5 安全指引](https://cheatsheetseries.owasp.org/cheatsheets/HTML5_Security_Cheat_Sheet.html) 建议不要将会话标识放在 localStorage，并说明 HttpOnly Cookie 可降低这一风险。

## 本地验收步骤

1. 打开 `http://localhost`，使用最新交付的账号登录；账号应用状态以管理员验收记录为准，密码不写入本文件或仓库。
2. 如需测试新用户，退出后点“注册账号”；填写有效邀请码，用户名为 3–64 位 ASCII 字母、数字、下划线或短横线，密码为8–128字符且包含字母和数字，确认两次一致。
3. 新用户作品库应为空，不会取得原示例账号的书籍或模型连接。建议用独立浏览器配置/无痕窗口同时比较；同一浏览器配置的标签页会同步切换账号。
4. 从原示例账号复制作品链接，在另一个普通账号中打开应被拒绝；不能读取章节、控制任务或订阅对方写作进度。管理员仅在专用管理接口中具有跨用户只读权限。
5. 在“账号”中改密，然后确认旧密码和旧会话失效。测试生成需主动填写有效模型连接，实际生成可能产生模型费用，本次启动验证未调用付费模型。

数据库和配置升级前备份位于项目被忽略的 `.local/acceptance-20260919-135611/`。备份含敏感配置/账号数据，不能公开上传；`.gitignore` 和 `.dockerignore` 已排除该目录。旧镜像保留 `pre-auth-20260919` 标签。备份没有做恢复演练，不等于已验证灾难恢复。

当前已完成本地启动与认证启用，尚未完成本表的公网加固；不要将本机验收通过解释为生产安全验收通过。
