# 中文小说表达规则

2026-10-24：接入现有长短篇写作、审核、修订与补写提示词。规则集中在
`src/myink/workflow/prose_rules.py`，不增加模型调用、路由、数据库字段或前端开关。

## 范围和优先级

设定、计划与既有硬约束优先，其次是作者文风档案、样本及人物口吻，最后才是通用表达建议。
现有否定对举、连续排比硬禁令及确定性校验保持不变；本次没有放宽这些规则。

新增建议关注空泛铺垫、重复解释、机械起句和比喻、段尾升华；保护心理描写、口癖、
刻意重复、意象呼应、悬念与留白，不把小说统一改成短句或口语。
修订保留事件、动机、时序、因果、设定与伏笔，受当前全文/缺章/补丁范围约束。

审核必须指出原文和具体问题。长篇一般只报 minor/hint，不为可选润色触发重写；
持续妨碍场景理解且有证据时可以报 major/rewrite；不因纯表达问题 replan。
短篇只将确实必须修改的问题写入 issues。严重度与路由仍由现有审核链路处理，
这些提示词不是确定性保真或路由保证。

## 验证边界

消息边界测试覆盖长篇生成、全文修订、局部修订、短篇生成、缺章补写、整篇改稿与两类审核。
它只证明提示词接入，不证明真实模型生成质量提升或 AI 检测结果。

真实模型评估应固定模型、温度、计划、上下文与样本，对比旧提示词与新提示词，
盲评自然度、人物声音和剧情保真，记录 token、耗时与额外修订次数。
至少覆盖以下素材，未进行真实调用前不能宣称这些行为已验收：

| 素材 | 预期检查 |
| --- | --- |
| 每段动作后都用同义句解释情绪的初稿 | 减少重复，保留有新信息的心理描写 |
| 一贯简短且有固定口癖的角色对话 | 保留口吻，不强行增加句长变化 |
| 同一意象在伏笔与回收处出现 | 保留呼应，不因重复误报 |
| 含否定、推测、数值与未揭晓身份的片段 | 不改变确定程度、设定和悬念 |
| 已自然流畅且无审稿问题的片段 | 不制造修订工作量 |
| 缺章补写与局部补丁 | 仍只补缺章或问题句段，输出标记可被解析 |
