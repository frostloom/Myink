# 本地端测反馈第二轮：实现与验证

范围：本轮九项端测反馈，以及追加的长篇分步建书、创作设置完整只读题材、后续章节可编辑规则。保留此前未提交修复；不涉及 Pi，不推送或更新远程部署。

## 已实现

- 删除管理导航按钮；退出状态按认证状态显示登录入口。
- 管理端用户详情展示用户信息，作品按用户分组；详情使用独立页或可关闭弹窗，压缩标量字段和资源卡片留白。
- 用户与管理员导航改为随外层滚动容器的 sticky 卡片；手机使用紧凑横向导航。
- 短篇对话等待提示位于输入框上方，成功、失败、取消、账号变化时结束；方案卡片增加冲突及收束摘要。
- 长篇建书拆成作品信息、设定、大纲三步，支持返回与草稿恢复。长短篇均在创建流程弹出资源卡片；资源保存失败不触发写作，短篇重试复用同一作品。
- 全局文风库下新增写作资源。发布目录与个人版本具有来源关系，复制、编辑、更新使用代次校验；平台覆盖个人修改需明确确认。
- 创作设置完整展示当前题材及规则；长篇题材建成后锁定。文风、创作规则、表达规则可编辑为本书版本，仅用于后续新任务。
- 既有快照不因普通保存隐式升级；旧长篇首次启用资源保留冻结主辅题材。个人自动题材在设定与大纲提案阶段生效。
- 冲突时保留编辑内容，重新载入最新版本需确认；不会自动升级代次强行覆盖。
