## Tasks
- [ ] 1. 导航认证与紧凑后台：AdminRail/ProjectRail及布局CSS；移除无用入口、登出状态回归、sticky/手机布局；作品按用户分组、详情标量紧凑渲染，后台相关测试和浏览器检查。
- [ ] 2. 短篇对话：等待提示生命周期、卡片设计；不触碰资源提交逻辑，覆盖成功/失败/切会话，桌面手机无覆盖。
- [ ] 3. 资源后端：来源版本关联及幂等迁移；个人编辑/覆盖确认API；自动题材、未来个人资源快照、长篇题材锁；鉴权、CAS、旧数据、运行快照不变回归；明确前端契约。
- [ ] 4. 全局资源库与建书弹窗：复用管理员卡片/字段，新增侧栏入口路由；创建流程直接选择并编辑；个人来源更新覆盖确认；隐藏手选题材资源，长短区别；针对前端回归。
- [ ] 5. 独立审查、整体验证、截图检查与验收报告；更新myink记忆。

Review Focus:
- 退出后管理员/访客视图、刷新和多标签状态一致。
- 移动端悬浮导航不挡输入；点击出现内容在视口内。
- 来源关联不能越权引用他人的个人资源；未发布平台草稿不泄漏。
- 用户覆盖必须明确确认，目标平台发布代次与个人代次同时CAS，旧草稿冲突不丢。
- 自动题材按作品题材而非用户随选；长篇所有写入口守锁，短篇不误锁。
- 编辑个人资源确实影响未来写作；已经入队任务和既有书快照不静默变化。
- 选择弹窗取消/保存失败不应重复建书或提前生成。

Ruling: 用户已给出具体九项规则并保持连续执行授权，按上述明确语义直接实施，不重复要求逐步批准。
