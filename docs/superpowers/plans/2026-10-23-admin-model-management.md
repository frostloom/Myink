# 管理员导航和模型管理实施计划

**Goal:** 按用户指定的 platform 交互提供展开的侧栏、模型列表和单模型新增编辑。
**Architecture:** 沿用 React Router、平台配置 API 和既有密钥只写策略。模型单独保存时保留配置中其他模型、角色、默认值、提示词和题材；版本冲突保留草稿。旧 configuration 地址重定向到模型列表。
**Tech Stack:** React、TypeScript、CSS Modules、Vitest。
**Spec:** 用户确认与 aixcoder-platform-frontend 相同：每模型单独配置服务商、地址、Key 和模型 ID。

## Constraints
不增加依赖，不修改参考项目，不提交推送或部署；只修改管理员 worktree。只提供 Myink 实际支持的 OpenAI 兼容和 Anthropic 原生协议，不复制代码补全等无关能力。

## Review Focus
新增取消不能写入；编辑留空密钥保留；删除要确认并清除对应角色引用；冲突保留草稿；页面加载不自动调用供应商。
