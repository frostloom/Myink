# 上线端测反馈修复计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement task-by-task.

**Goal:** 完成用户 2026-10-27 七项反馈，优先修复确认后无法完成落盘，再改善实时生成及全站详情交互。
**Architecture:** 继续使用 Vue 和现有 API/SSE；修复状态边界与导航，不恢复 React，不涉及 Pi。生产数据仅用于只读定位，回归使用隔离数据。
**Tech Stack:** Vue 3、TypeScript、Vitest、Playwright、Python pytest。
**Spec:** 本会话用户七项要求及五张截图。

## Global Constraints
- 保留已有未跟踪文件，不纳入提交。
- 不自动部署；完成代码及验证后报告。
- 写作资源创建时可选，已有作品显示其快照并可显式检查版本更新；不在正文顶部提供中途替换资源入口。
- 用户不需要滚动寻找点击产生的新详情；长内容用独立页面与返回机制，短内容用视口内弹窗。
- 延续现有主题字体、颜色与间距，减少重复信息，不做装饰性重构。

## Review Focus
- 确认已保存但恢复失败，重复点击/重开能安全继续，不能调用不存在的批次。
- 同一任务重跑的新 attempt 不得混入旧计划/正文；失败仍能找回已保存正文。
- 资源无更新、409、网络失败时关闭按钮仍可关闭，不把关闭解释为成功更新。
- 详情深链和浏览器返回正确，移动端弹窗与操作处于视口内。
- 用户/作品/任务/运行职责清晰，保留关联导航而非重复完整内容。

## 已确认的根因与实现
- 确认后恢复调用旧 `/batches/{id}/resume`；改用统一 `/tasks/{id}/resume`。确认记忆与章节终态分别验证，不能据截图推断所有正文未保存。
- 同任务新产物替换时旧正文/计划残留；按产物身份退休旧流，并允许 HTTP 失败/取消终态结束等待。
- 原“重写”实际经过 Planner；现在恢复已落正文的批准计划，另设显式重新规划入口和 `replan` 请求字段。
- 局部修订先清预览，收到并校验补丁后发送实际新正文，不把补丁 JSON 当正文流。
- 后台长章节独立路由，短运行详情视口弹窗；主动打开置顶，返回恢复列表筛选/页码/位置。
- 资源选择集中到开写前，已开写显示快照与显式版本更新；后端 Project 锁与入队占位协调，单连接池回归防嵌套借连接。
- 更新关闭是本地操作；忽略请求失败不会困住弹窗，旧忽略回执不会覆盖重新打开后的状态。
- 本地 CI 禁用 `.env`，避免导入开发模型配置污染测试；本轮测试服务已重新建立后初始化。

## 范围边界
- 不修改生产记录，不声称截图对应章节已被自动补偿。
- 不推送、部署或改动其他分支；保留已有无关未跟踪文件。
- 浏览器验收使用构建产物与受控回环 API/SSE；数据库持久化另由隔离 PostgreSQL/Redis/RabbitMQ 回归验证。
