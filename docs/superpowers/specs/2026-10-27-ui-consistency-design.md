# 全站交互与布局一致性

Myink 是长短篇写作工作台。本轮处理导航跳动、管理导航拥挤、个人资源未分类、相同编辑表单颜色不一，并核对全部路由页面的布局和交互状态。保留既有 Vue、功能与用户自定义主题，不做品牌换肤。用户已授权连续执行，不逐步确认；不提交推送远程。

## 视觉约束
沿用主题 token（实际值以 tokens.css 为准）：纸面底色、浅纸面板、墨色正文、柔和绿主操作、描边、错误色。使用既有中文系统字体，正文与标题随用户阅读字号 token；输入控件与按钮统一主题，保留桌面40px、触屏44px，管理导航提升到44px触达，表单同组件同样式。布局左对齐，正文有清晰宽度，资源分类—卡片—详情分层，不在信息流末尾突然展开长编辑表单。

```
[稳定导航] [页面标题 / 当前状态]
[作品列表] [分类 + 搜索]
[本书链接] [资源卡片 ...]
[全局链接] [打开编辑 → 固定视口对话框，固定头尾 + 内部滚动]
```

## 行为
- 导航在同账号切页时保留已有书单和滚动位置，不先清空再加载，不因页面数据等待而消失。账号切换必须清理缓存，不能泄漏前账号书单。固定外框与全站占位保持上一轮尺寸。
- 管理导航条目更舒展，至少44px触达；菜单与账号操作分区。保持滚动可达。
- 个人写作资源与管理员使用相同类别、顺序和清晰分类控制；列表内容有界，搜索与类别一起作用，空态能恢复。
- 同资源类型使用相同字段组件和主题表单；查看/编辑/保存/取消语义一致，保留个人版本覆盖提示与长篇题材不可变。
- 全路由审查加载/错误/空态、返回、弹窗焦点与可关闭、窄屏溢出、控件主题、长内容以及滚动。只改有证据问题，记录已审范围和无法验证范围。

## 验证
先复现并加行为回归；全前端lint/test/build；隔离接口三引擎截图与交互，包括延迟请求下切页、书单滚动、用户切换、长编辑表单主题一致、分类搜索及桌面/手机。只有真实运行证据可以记为通过。验证后更新localhost，远程不动。
