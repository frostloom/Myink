# Pi 观察、提案与可验证任务接入

用户授权继续本机管理开发、自主判断和阶段推送，要求指标可用于简历。复用现有观察指标、任务包、隔离基线、独立审查、管理器inbox；不改上游Pi核心、不合main或部署。沿用现有Python实现，用户已选择不逐项确认。

本轮读取宿主固定SHA的JUnit XML、原生cycle receipt及collect_snapshot JSON，归一观察，不执行输入源码/测试或读取原始日志正文。XML只接收有界UTF8，无DTD/entity定义；保留失败/错误/跳过/重复项及未知，不把缺值当0。指标混杂、样本不足、不可测均不触发执行。原生执行未知使批次停下对账。

候选由明确的宿主规则映射到预先固定的task_package请求：rule选择source_id+observation_id、触发条件、最少样本、优先级及原有源码/gold/文件范围。观察描述不是权限；不自动推断gold，不将模型文本当路径或审批。没有匹配规则的信号保留，只有通过当前源/测试SHA检查的规则可进入候选。

候选按源码+gold+文件范围去重，保留每条规则的触发/拒绝/重复/延后结果。显式执行时调用原task_package.freeze及package_baseline.execute重现，不在宿主import候选。绿色、错误、跳过、清理失败、超时、变化或库存不匹配不进入合格目录。整批最多20个基线调用、1800秒，默认只读，不触Docker、模型或费用账本。

合格提案仍无执行权。发布桥接只接收固定提案报告与已有独立封存cycle：源、gold、文件、库存、复现和原目录须一致，再通过原local_cycle预检，向独立私有inbox原子发布严格manifest；新费用检查点和两阶段审查不绕过。发布不调用模型、不自动修改管理器状态、不自动采纳。目录/数据/锁保护沿用私有权限、单链接和规范化路径规则。

指标分母分开：观察总数、信号数、规则总数/触发/拒绝/重复、唯一候选、基线执行器调用、合格失败库存、发布数。未知/缺规则/不合格结果不删除；Python基线函数调用不冒充真实容器或模型次数。完整指标报告保留证据SHA、运行模式、来源与未测值，不能据单批实验报生产成功率或效率提升。

验证：TDD边界、未知/混杂、重复/无映射、漂移/路径/恶意XML、基线成功/绿色/错误/取消及发布权限；原固定checker真实多分支实验；独立代码审查和必要作者TDD修复；当前runtime/新身份/新审批验证一次真实管理器接线，原账本不复制/未知不释放。所有失败原样保留。
