# 第二轮端测：紧凑导航与建书资源

依据：本会话用户九项反馈及五张截图。延续用户连续执行、无需逐步确认的授权，主线main；不提交/推送/远程部署，不覆盖前一轮未提交修复。

1. 删除“管理导航”折叠按钮，导航直接可用；退出登录后所有侧栏显示登录，不残留管理员动作。
2. 管理员与普通侧栏为页面内sticky悬浮卡片，随主滚动容器保持可达，不使用固定全高空白栏。手机导航紧凑可滚动，不遮挡正文/输入。
3. 信息密度整体收紧：元信息采用紧凑行/网格，详情长文本正常换行，不把每个标量变成大块。正文阅读保留舒适行距，不粗暴压缩编辑器。
4. 用户页展示账号统计，去掉“查看作品/任务/运行”等绕路按钮。作品栏目按用户明确分组，保留作品详情和正常返回。
5. 短篇对话请求中及回复中在输入框上方显示“正在努力构思中，请稍后”，独立布局占位不盖住输入；完成、失败、取消、切会话后正确移除。建书卡片提供标题、题材、篇幅、人物压力/冲突/收束的清晰排版。
6. 长短篇确认建书流程直接弹出资源卡片选择，不再额外跳转资源页才选。题材包/题材规则自动按作品题材绑定，不在选择器列出。角色提示词/知识库按原运行环节自动生效，不作为手选组合。
7. 文风库下新增全局“写作资源”。采用管理员相同资源卡片和编辑字段，显示已发布资源（不公开管理员未发布草稿）。编辑保存为账号个人版本，不修改管理员源；未来建书选用个人版本。
8. 平台与个人资源建立明确来源/版本关联。发现管理员更新时提示个人修改将被覆盖；只有用户显式确认后同步，CAS防止并发覆盖。已有作品和进行中任务使用冻结快照，更新需显式采用，不能偷偷修改运行中输入。
9. 长篇建书完成后题材不可更改，后端覆盖所有题材写入口并保留无关设置可编辑；短篇不套此限制。全局资源编辑仅影响将来的选用，不能偷偷改已建长篇题材。

实现选择：沿用Vue、现有主题与资源编辑器，不引入UI依赖。个人资源增加可迁移的来源字段，自动资源也可建立个人版本并在未来任务快照生效。旧无关联个人资源继续独立使用。

验证：针对性先红后绿、鉴权/并发/长短规则后端测试、前端全量lint/test/build、固定最终产物三引擎桌面/手机端测；数据库与前端重验证串行以避免上一轮资源争用。不可把环境失败、跳过当通过。

## 本轮追加：分步建书与后续章节规则

2026-10-27 用户补充：长篇建书分作品信息、设定、大纲步骤，提供返回，保留草稿，切步内容从顶部可见。创作设置完整只读展示当前题材；文风、创作规则、表达规则迁到创作设置，以资源卡片提供编辑。规则修改在后续新入队任务生效，已生成章节和运行任务快照不变。此指令取代此前“开写后禁止任何资源组合修改”的范围限制；题材仍固定。用户个人资源库与本书规则覆盖区分，平台覆盖个人版本须明确提示确认。
