# 模型连接错误提示：修订设计

日期：2026-09-22。状态：已根据书面评审意见修订；尚未实施。

## 目标与边界

让用户在模型列表探针、连接测试和实际写作失败时，能区分连接失败、请求超时、配置错误和上游拒绝，并获得可操作的提示。延续既有字符串错误契约，不更改登录、租户隔离、数据库结构或队列路由。

用户已认可探索结论和交付顺序：先修复 CI 基线，然后依次实现不可达提示、局部修订、短篇和榜单换源。每个目标独立验证、提交、推送并核对同一提交的 GitHub CI。本文件只设计不可达提示，Jev 完全不在范围内。

2026-09-22 用户补充并澄清：可以修改相关计划，但最终目标不能明显偏离；不要多余的常驻说明、小字提示和引导段落，**必要的弹窗和提示组件需要保留或补齐**。长页面上的反馈不能只放在不可见的页首或页尾，创建书籍时已有类似体验问题。原需求中的自部署地址只作为可选失败详情，不扩展成常驻界面引导。

最后澄清：常驻说明并非全部禁止。必要的操作指引、格式约束和风险说明可以保留；删除的是幼稚、重复、显而易见、对完成操作没有帮助的说明。判断依据是信息价值，不是文字是否常驻。

本设计修订 `docs/UNREACHABLE-HINT-PLAN.md`，不把其中的旧行号、依赖版本和推断当作实施依据。

## 已核实的现状

- `providers/probe.py` 使用 httpx，已单独处理 HTTP 状态错误并提取响应体信息；其它异常只格式化为字符串。
- `providers/deepseek.py` 实际使用 OpenAI SDK；`generate` 和 `generate_stream` 各自捕获异常。SDK 会把底层网络异常包装为 `APIConnectionError` 或 `APITimeoutError`，它们不是 `httpx.TransportError` 的子类。
- `providers/anthropic.py` 使用 httpx，有独立的同步和流式异常出口。旧计划仅修改 DeepSeek，会遗漏这条真实用户路径。
- `providers/base.py` 的降级链还会捕获异常，但没有各连接的 API Key；不能在那里臆造脱敏上下文。连接适配器是本次主要格式化边界。
- `ModelResponse.error`、探针响应、任务记录与页面展示已有字符串通道，可以复用。
- 重试次数、退避和降级策略是另一项行为改变；不能由提示分类顺带改写。

## 方案比较与选择

1. **选择：共享错误格式化，接入全部模型调用出口。** 新建一个小模块，在探针和两类 provider 的同步、流式出口使用。保留上游拒绝原因，按可靠异常类型分类，并保留原重试行为。改动可独立测试、回退。
2. 仅改探针。改动少，但会出现测试连接时说得清楚、真正写作时仍报不透明错误的体验断层，不满足目标。
3. 全链路改为结构化错误码并同时调整重试。长期可以考虑，但当前需要联动 API、事件、任务和前端，不与这次提示改进捆绑。

## 分类契约

对 SDK 包装异常沿显式 `__cause__` 查找可识别的底层原因；必须防循环并限制遍历深度。优先使用真实类型，不靠异常消息中的英文关键词猜测，也不靠域名或 IP 推测地区封锁。

| 类别 | 输入例子 | 用户应得到的信息 |
|---|---|---|
| 连接失败 | ConnectError、ConnectTimeout、ProxyError；无更具体原因的 APIConnectionError | 本部署未能建立到模型服务的连接；检查服务地址、代理和部署网络。不能断言服务永久不可达 |
| 等待或传输超时 | ReadTimeout、WriteTimeout、无具体原因的 APITimeoutError | 请求超时，服务可能响应较慢；不能说已确定是网络封锁或密钥错误 |
| 本地连接容量 | PoolTimeout | 等待可用连接超时，建议稍后重试；不推荐用户改密钥或自行部署 |
| 配置/客户端协议 | InvalidURL、UnsupportedProtocol、LocalProtocolError | 检查服务地址、协议或请求配置；不显示网络不可达引导 |
| 传输中断/远端协议异常 | ReadError、WriteError、CloseError、RemoteProtocolError | 通信中断或响应协议异常；不把它等同于无法建立连接 |
| 上游拒绝 | HTTPStatusError、APIStatusError，包括 401/402/404/429/5xx | 保留状态码和经过脱敏、限长的上游错误原因，不混入不可达指引 |
| 其它错误 | ValueError、JSON 解析错误等 | 保留经过脱敏、限长的诊断信息；不得被误分类为网络错误 |

OpenAI SDK 支持的底层 HTTP 库可能随已安装版本变化。实现必须覆盖项目现有 SDK 包装类型，并用真实包装异常的测试证明生成路径有效；不能只对裸 httpx 假异常测试。若需要兼容已安装的 httpx2 类型，采用可选兼容处理，不新增强制依赖，不依赖 SDK 的私有函数。

## 模块与数据流

新增 `src/myink/providers/errors.py`，负责分类、提示生成、已知密钥脱敏和长度限制。接口采用 `format_provider_error(exc, *, api_key, self_host_url)` 返回字符串；分类是模块内部细节，不变更公开 API schema。

- `probe.py`：保留成功结果与 HTTP 响应体提取语义；模型列表、连接测试的异常路径使用共享模块。
- `deepseek.py`、`anthropic.py`：同步与流式出口一致使用共享模块；返回到 `ModelResponse.error` 的内容与 warning 日志使用同一安全字符串，不再直接记录网络异常原文。
- 不改 `FallbackChain` 的调用顺序，不改变流式失败后的 reset 行为，不增加模型调用。
- 不修改出站地址守卫，不增加内网例外。MCP 错误翻译留到榜单目标，不在这里假装其取消异常已经能精确分类。

## 配置、安全和呈现

- 新增 `SELF_HOST_URL`，默认空字符串。只修改 `Settings` 和 `.env.example`，不覆盖用户现有 `.env`。
- 只有连接建立失败才可附加自部署指引。留空时不出现链接，也不要求用户把已在本地运行的应用再次部署。
- 指引地址只接受无用户名密码的 HTTP(S) URL；无效值不显示，不发出网络请求。
- 网络类错误不附带底层 URL、IP、请求头或异常原文。其它可诊断信息至少移除本次调用已知 API Key；脱敏先于截断，最终错误长度上限为 300 字符。
- 不新增幼稚、重复或显而易见的说明。必要的操作指引、格式约束和风险说明可以常驻，文字保持简短。反馈必须可见，不能仅依赖页首或页尾的文案。
- 字段校验靠近字段显示并将焦点移到首个错误；普通操作结果可用视口内通知；阻断创建/生成流程或需要用户作决定的错误使用对话框。不得每次成功都弹窗，也不得使用浏览器原生 `window.alert()`。
- 优先复用现有 React、CSS Modules、设计变量和弹窗模式，按 `redesign-existing-projects` 的先审查、再针对性修正流程工作。不更换框架、字体或整页布局，不新增无关视觉效果。
- 对话框须支持键盘操作、明确关闭、焦点管理与焦点恢复，保留表单已填内容；重要错误不得在用户读完之前自动消失。通知须有可访问的状态播报，不抢夺输入焦点。
- 本目标只处理模型探针/连接保存相关反馈的可见性，创建书籍的同类反馈跟随短篇与建书目标处理，避免本次扩展成全站反馈系统改造。交互测试须覆盖用户滚动到页面下部后仍可看见失败反馈，以及重试/关闭不会重复提交。
- 不承诺自动检测 DNS 污染、地域限制或永久不可达；这类结论超出异常类型能证明的范围。

## 验收与回归

1. 纯函数测试覆盖表中各类异常、空消息、循环 cause、未知异常；不依赖外网或真实密钥。
2. 同样的连接失败经探针和 OpenAI/Anthropic 同步、流式调用，均能得到一致类别的提示。
3. 使用真实 SDK 的包装异常构造或受控 transport，避免“裸 httpx 测试绿、SDK 实际漏分类”。
4. 401/402/404/429/5xx 保留有效状态与上游原因；不含网络不可达或自部署误导。
5. 密钥脱敏、300 字符限长、自部署地址开关与非法地址处理均有行为测试；日志同样不泄露已知密钥。
6. 断言重试次数、降级顺序、流式 reset 行为不变；本次不以缩短等待为验收承诺。
7. 运行模型探针、custom provider、streaming、environment routes 等相关测试，再运行 Python 全量回归。如果改动前端样式，还须运行前端 lint、全套单测与 build。
8. 实际检查长页面下部操作、长错误文案、移动宽度和键盘关闭/焦点恢复。若当前环境不能完成浏览器检查，必须记录未验证，不以代码推断冒充视觉验收。
9. 独立提交本目标，推送后按提交 SHA 检查 GitHub 的 Python、前端、镜像构建三个 job；全部成功才交付为完成。

## 不包含的工作

不改变模型选择、思考配置、费用估算、输出截断处理、重试预算、任务恢复、榜单配置、管理员权限或数据卷。短篇的输出结束原因保留、局部修订的路由预算和榜单 sidecar 都有各自独立设计与验收。
