## 独立审查后的修订

| 发现的问题 | 设计中的修订 |
| --- | --- |
| 费用限制只有禁止绕过的文字 | 分离秘密与策略执行域，受控命令和模型出站，增加直接 HTTP、嵌套调用及凭据反例验收 |
| 尚未部署候选时 Pi 崩溃，缺少恢复归属 | 独立 maintenance epoch，记录原稳定服务与暂停任务；维护撤销与候选回滚分别处理 |
| 候选 Worker 启动就消费生产消息 | 持久维护消费屏障，隔离合成探针；当前所有者对账后才解除 |
| 限时收尾后不能证明已经安全暂停 | 按任务类型规定确认矩阵；无法确认就取消候选路径并保留未知状态 |
| 只证明 schema 兼容，漏掉旧工作流状态 | 旧 checkpoint 到候选续跑、候选到稳定版恢复及消息 payload 纳入门禁 |
| 本机通过被误当服务器可用 | 本机协议与真实服务器容量、备份和恢复校准分别验收 |
| 迁移期限与人工安全交接缺少边界 | 锁等待、语句期限、事务结果和最晚开始时间；不可安全取消操作不自动执行 |
| 维护页正常不能证明数据库或备份正常 | 独立业务探针与 PG、备份、调度心跳；遥测缺失也报警 |
| 固定磁盘余量忽略备份、镜像和冷缓存增长 | 按本轮预计新增峰值加保底余量，并在每个重阶段重新核对 |
| 实验分支继续推送可能改变 ready PR | 工作分支与步骤候选分支分开；候选冻结，变动撤销旧验证 |
| 固定所有提示词会阻止合法提示词优化 | 除声明实验因素外固定其他条件，并记录基线与候选因素版本 |

这些修订补齐设计条件，不表示消费屏障、发布协议或预算隔离已经实现。

## 本轮检查与边界

完成文档回读、结构与占位检查、明显密钥格式检查，以及主工作区和隔离工作区 Git 状态核对。只有两份方案文档属于本轮变更，主工作区原有文件修改保持原状。

本轮没有运行 Python、前端、Go 回归、构建、恢复演练或付费模型请求。首次实测仍需遵守累计最多 100 次请求、估算 10 元；服务器未来每日额度不自动启用。
