初始生产基线变化、运行包权限/字节码拒绝、owner001无有效gold报告、owner002分派前时限拒绝，以及首次恢复因空WAL/SHM存在而中止，均保留原文件和日志。恢复演练使用SQLite正式checkpoint API确认busy0/帧0后关闭侧文件，再建立全新最新检查点；没有手动删除WAL或越过未结算状态。
