## 逐篇证据

### P01 / clock-evidence：未通过；权限信息自相矛盾

**已通过：** 同刻手机10:00:00、门禁09:58:00、摄像10:01:00，记录与当前三分钟差值正确；历史22:06保留，不直接套昨晚，明确需历史校时。原始日志、昨晚录像、当前读数三类材料均决定保护，实际导出后交接签字，再找后勤校准。门卡已封未重封，身份与来源未知。末尾值班员让去问保安，不是实际引入新的案发目击证人，不能凭未来可能询问就扣这一项。

**确定内部矛盾：** 值班员先说“导日志要管理员口令，我没有”，随后没有管理员到场、获取口令或权限变化，却“把口令输入框调出来……用手掌挡着键盘敲几个键”，接着照做整段导出。对话先建立不能导出，动作马上按能导出执行；不是一般省略鼠标点击，而是关键权限障碍无过程消失。

**可润色：** 陶准说“要动，也得先证明昨晚也慢两分快一分”，容易让人理解为证明后可以改历史日志；前后都说不改，实际也未改，故不判历史改写。宜改“要换算昨晚时间，得先证明”。结尾明确手机10:04，而中段摄像画面仍10:01，可能发生在10:00—10:00:59并无确定矛盾，不能替文本强判时钟停止。

**文风与冗余：** 担责、考核扣分、签字用途具体，有角色动机；但读数、权限、交接、录像范围、追问谁进入多次兜回，篇幅明显偏长。“摄像头外壳他看不见、也没打算从外壳看什么”是对验收反例作答的痕迹，不是人物自然会想的事，可删。

### P06 / clock-evidence：完整通过

**证据：** 并排当前三读数与三分钟差值，巡检表记观测；明确昨晚22:06不改、当前偏差不直接扣到昨晚、须历史校时。原始日志已有只读备份，并实际核22:06；录像文件列表只是初查，但随后明确“录像先别覆盖”“今天之内把该拷的拷出来”，不是仅存索引。末尾统一要求日志、录像、对时记录保护，问设备科权限、约周一校时。没有实际先改钟或直接锁人。

**时间计划：** 今天周六、录像三天循环，不等于等周一才拷；原文已要求今天之内拷出，故不能报“等到周一录像必被覆盖”。校时延期是流程选择，不是未安排校准。

**文风：** “照实写读数，偏差是我算的”把值班员担责与陶准求证分得较好；值班员只能查、什么能导、维修权限如何走的对话总体自然。比P01收束更集中。

**可润色：** 旁白“他要的就是这个”“眼下能确定只有一件事”等解释偏多；同一组读数与现在/昨晚边界讲了几轮，可以压缩。末段“手机收回来又看三个并排数字”视点略含混，可能回看记录/终端，宜写清，但不影响前面已建立的同步测量。把“只有维修权限”说成有维修权限但无校时授权会更清楚，不是已经越权校时。

### P02 / family-decision：未完整通过；女儿共同就坐未落实

**已通过：** 先“就在学校”回避，后亲口承认便利店十点到六点、夜班影响早课，奖学金未选上。母亲亲手关小火、之后端锅关火，申请签名空白、不替女儿决定。手机已实际打开，周三两节、周五一节有红标，并问补课，不是只约以后看。

**明确缺项：** 母亲“在小桌对面坐下”，女儿之前一直站着挪书包，之后只有递手机、头挨头看、端碗，没有坐下或已经坐姿的证据。不能仅因母亲坐对面就替女儿补一张凳子。与先前相同门槛一致，不要求最后一句仍核课表。

**次要完整度：** 女儿动机停在“你每天三点起来发面，我……”；语境能懂她想减负，但不如直接亲口说不想再要钱清楚。此处记为动机表达偏弱，主要拒收依据仍是共同坐桌事件缺失，不能据未说完就断言实际打工动机已变。

**文风：** “我管不管，你人都不在教室”有口语力度，最后让把申请收起免油星溅，情绪落在生活动作上；“我不打也不骂”“年轻人眼下青原以为看手机”较常见。整体不比已审现实佳作明显更有辨识度。

### P03 / family-decision：未完整通过；共同坐桌状态未落实

**已通过：** 回避图书馆后亲口承认夜市砂锅摊夜班；题目没有指定只能在便利店打工，换普通夜间工作完全允许。亲口说奖学金落选、不愿母亲为钱多蒸包子，动机完整。母亲关小火端锅；三次课均逐项追问，申请未签，母亲没代决定去留。

**具体缺项：** 只有母亲“在小桌对面坐下”，女儿递手机、喝奶，没有坐姿；未建立两人坐桌共同核对。不能因母亲说对面、女儿能喝到碗就默认女儿已坐下。

**文风：** 女儿身上油烟味、砂锅摊六十/周末多二十、母亲面粉指甲，职业与劳动细节较具体。母亲“不点名就不去”“算来算去把自己算进去”的追问有压力；尾段最后问今晚是否还上班，冲突未突然和解，这点好。

**可润色：** 母亲说十一点“起来和面”与后文每天早上三点起床习惯口径有张力，可能夜里某次临时起身，未给绝对只能三点和面的规则，不判硬错。少写一步倒奶属于日常动作压缩，不当凭空出碗。整体语言比P02更具体，但完整门槛没有改善。

### P04 / single-action：未通过；药袋开场位置偏离已定初态

**确定初态问题：** 原题六尺裂缝，药袋固定在“靠近秦鹤这侧”的绳套；本文没有任何先行拉动，就开篇写药袋“离对岸还有两尺来远”。在六尺裂缝中，这已更靠师姐一侧，不是靠秦鹤一侧。直到这句后才要求别拉、自己试着抬绳；没有交代药袋此前如何移过大半裂缝。这是初始位置被换掉，不是允许的正常后续收绳发展。

**其余完成项：** 仍是同一绳/袋、一次短风与师姐收绳，实际收到未破，法力空腕仍伤，符烧尽；师姐说来路摸出去，秦鹤说这侧往北绕、进来时记了，可以自然理解为认得自己的返回路线，不强行要求逐字“原路”。双方约洞外、仍分侧，无瞬移和第二符。

**可润色：** 两次说数三下却直接起风喊收，属执行口令改了、非第二次施法；可删数拍预告。风先“往下压”再从下托，术法路径可转，不判普通物理力向错误。几次“最后一张、快灭、只剩一线”的结尾铺陈重复，成功后仍较拖。

### P05 / single-action：未完整通过；秦鹤自身来路返回未明确

**已通过：** 同一绳、袋已在套，一次短风配合师姐收袋，法力耗尽、右腕仍伤、符灭。师姐实际收到未破药袋。开头“距对岸三尺来远”在六尺中接近中段；“来远”是估计且袋可能在本侧向下垂，不能像P04确定两尺那样直接判已换至对侧，故不作硬位置违规。

**具体缺项：** 师姐明确“原路”，秦鹤则说“我这边有条干沟，顺东能绕到洞外松树”。没有说或其他叙述证明干沟就是他来时路线；后面也是向干沟试探。预定终态要求各自沿自己的来路，不是只要任何能出洞的新路。与此前同类样本的判定一致，应补来时路线依据。

**其他可润色：** 右腕先说不再动，施术却再翻腕，骨折人强行动作伴疼不等于恢复，不额外判“伤好了”。师姐已检查扎口未漏，后来秦鹤叮嘱别拆，检查外袋与打开内药可以不同，不判确定先拆后说别拆。成功后又问能否走、路线、再叫住别拆药，有停顿感；整体叙事自然程度尚可，利落度不显著优于已审修仙样本。

## 与已审文本的实质取舍

此前全是匿名标签，本报告不知道哪篇属于真实基线，因此不能诚实地把某一身份标为“基线”并作精确胜负比较。以下仅与已审文本池对照，供主代理揭盲配对。

1. **现实：** P03的夜市工作和油烟味，较常见便利店/裂屏套路更具体；P02较朴素。但二者共同坐桌事件仍漏，文风改善不能抵消验收缺项。与F13/F08一类已审佳作相比，没有更明显的角色主动性或关系层次优势。
2. **悬疑：** P06的权限责任对话是可靠的自然写法；P01则把权责写得更多却出现“没有口令—自行输口令”的硬矛盾。篇幅增多并没有稳定换来可信度。P06仍有可压缩的现在/昨晚解释，P01冗余最明显。
3. **修仙：** 主送药动作基本清楚，施术次数没有超支；“仅用原有自然配置”的文字并不差，但成功后反复询问伤势、路、余符和拆药，节奏仍偏长。两次都在既定初态/精确返回条件上出问题，当前证据不支持“不给修仙叠教学即可稳定满足全部结果”。

**发布意见：** 按完整验收应暂不放行此候选。先修复真实路由提示或生成约束是否稳定表达“共同坐桌、固定初始位置、自己原路返回”，再对新生成的独立样本复验。P01还需防止文本自己抹掉刚建立的权限障碍。不能直接人工补这6篇后宣布实际生成方案已稳定。
