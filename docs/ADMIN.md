# 管理面板与写作观测

管理员登录后默认进入独立的 `/admin` 控制台，无需创建作品。控制台保留用户、作品、任务、运行、分析、邀请码、反馈及访问日志，并集中管理模型、提示词和题材包。管理员角色独立于普通/VIP 任务调度等级。

## 权限

- 普通写作接口继续按作品归属隔离。用户侧只选择管理员发布的模型和题材，模型连接、后台角色路由、平台提示词及根题材包由管理员统一管理。
- 专用管理接口可跨用户只读查看作品、章节正文、设定、任务和节点调试记录，不提供删除或修改他人作品的操作。
- 管理接口每次验证真实 Bearer 会话和数据库当前角色；浏览器缓存、请求中的自报角色或用户头不能授予权限。配置写入使用独立的业务数据库事务，跨用户报表仍使用只读事务。
- 管理访问留有审计记录，响应禁止缓存。用户环境、模型连接凭据、密码哈希不在管理接口返回。

服务器上的角色管理命令（只针对已存在账号）：

```sh
docker compose exec myink-api myink set-role zlx admin
```

变更角色会撤销该账号旧会话，需要重新登录。降为普通用户时将最后一个参数改为 `user`。密码重设继续使用交互式 `myink reset-password`，不要把密码写入命令参数、源码或部署文件。

管理员的第二因子（TOTP）在账号页自行开启，默认关闭。认证器丢了或换手机后，服务器上的这条命令是唯一入口：

```sh
docker compose exec myink-api myink mfa-disable zlx
```

它清掉密钥并撤销该账号全部会话，之后凭密码即可登录；确认无误后再用账号页重新绑一个新认证器。没有恢复码，也不要为了绕过它去手工改库。机制细节见 [AUTH.md](AUTH.md) 的「管理员第二因子」。

容器启动使用 `myink init`：升级结构，但默认不建账号、不建示例书。只有确实需要开发示例数据时才手工运行 `myink init --seed`；不要在已有实际账号的库里用它补数据——它遇到缺失的 demo 账号会新建一个，而不是复用你现有的账号。

## 阅读指标

- 总览、用户与作品统计来自数据库聚合；列表分页，正文和节点详情按需读取。
- `cost_est` 是已记录的费用估算，不是供应商账单；缺少价格或历史费用的记录不能据此推断真实花费。
- 节点耗时来自已记录的 `duration_ms`；零值可能表示没有测量。任务创建至最后更新的时间跨度包含排队、暂停和人工等待，不能视为纯模型运行时间。
- 全部节点列表还包括没有任务编号的建书、整书大纲等调用，不能只看任务列表。
- 新的输入、输出、工具调用和召回快照有大小上限，并展示脱敏/截断标记；历史未保存的部分不能事后补造。脱敏识别常见凭据字段与格式，不承诺识别正文中任意形式的秘密。
- 记录会随使用增长，部署时仍需规划存储容量、留存和归档；本次不自动删除历史记录。
- 大小限制针对新增调试快照与管理接口响应；原流程后续还要读取的规划、审核等业务字段保持完整存储，不受新增快照限额覆盖，以免观测改变写作决策。

## 公网部署边界

当前管理查询复用 `ADMIN_DATABASE_URL`，在管理员鉴权后开启只读事务，普通连接和RLS规则不变。应用层只读事务不等于数据库凭据最小权限；公网加固应拆出专用只读报表角色，并完成 [公网检查清单](archive/PUBLIC-DEPLOYMENT-CHECKLIST.md)。增加管理面板不代表已经完成全部公网安全加固。

## 平台资源配置

「模型」中添加 OpenAI 兼容或 Anthropic 原生连接，填写显示名称、请求地址、真实模型 ID 和 API Key。管理员可拉取远端模型列表并测试连接。API Key 使用既有 `MODEL_CREDENTIAL_KEY` 加密存储，读取接口只返回是否已保存；编辑时留空保留原密钥。新连接必须填写密钥。请求地址沿用已有公网地址校验。

每个连接可独立控制启用和用户可见：启用但不公开的模型可作为后台规划、抽取、语义校验、审核和摘要模型；仅已启用且公开的模型出现在用户选择列表。至少为写作角色指定一个已启用的默认模型；未单独指定的规划、抽取、校验、审核和摘要角色沿用这个平台默认模型，也可分别覆盖。后台角色不会继承用户的写作选择。用户只选择写作和规划模型，不能改变后台连接或凭据。已下架、隐藏或删除的用户选择会失效，后续请求使用平台默认路由；不会恢复用户历史连接。

用户环境页保留思考模式、任务预算和扫榜偏好，不再提供请求地址、密钥和探针。历史账号和作品中的模型连接不再参与路由，也不向客户端返回。原用户模型配置写接口会拒绝请求，避免仅通过隐藏界面绕过管理。

「提示词」设置各角色的平台附加指令，实际请求保留程序内置的 JSON/正文格式和工具约束。附加内容进入生成请求和预算估算。清空某角色附加指令后恢复该角色内置提示行为。

「题材包」编辑既有目录中的卖点、子题材、禁忌、节奏、爽点、机制和世界提示。目录 ID 与题材选择方式保持不变；新作品从平台配置深拷贝快照，已有作品保留创建时的快照；主、辅题材都不随后续平台更改而变化。短篇对话建书在识别到目录题材时也使用该快照。普通用户可选题材，不能改平台根包或覆盖其管理字段。

配置存放在数据库单例表 `platform_configuration`，升级时先运行既有 `myink init` 建表；不需要迁移用户作品或手工改写历史连接。首次保存前可兼容部署环境的模型配置；显式保存空模型目录会关闭模型请求，单独调整提示词或题材时也须保留已有平台连接。配置保存带版本检查，多人同时编辑时旧版本收到 409，需刷新最新配置后重新编辑。平台配置数据库不可用时请求会报错，不会绕过配置策略。

部署前仍需设置独立且稳定的 `MODEL_CREDENTIAL_KEY`，并保留备份；更换密钥将导致已保存连接无法解密。新增表由既有初始化流程与应用角色默认授权管理，不使用只读报表连接写入。
