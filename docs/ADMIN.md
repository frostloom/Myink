# 管理面板与写作观测

管理员登录后默认进入独立的 `/admin` 控制台，无需创建作品。控制台保留用户、作品、任务、运行、分析、邀请码、反馈及访问日志，并集中管理模型、提示词和题材包。管理员角色独立于普通/VIP 任务调度等级。

## 权限

- 普通写作接口继续按作品归属隔离。用户侧只选择管理员发布的模型和题材，模型连接、后台角色路由、平台提示词及根题材包由管理员统一管理。
- 专用管理接口可跨用户只读查看作品、章节正文、设定、任务和节点调试记录，不提供删除或修改他人作品的操作。
- 管理接口每次验证真实 Bearer 会话和数据库当前角色；浏览器缓存、请求中的自报角色或用户头不能授予权限。配置写入使用独立的业务数据库事务，跨用户报表仍使用只读事务。
- 管理访问留有审计记录，响应禁止缓存。用户环境、模型连接凭据、密码哈希不在管理接口返回。

服务器上的角色管理命令（只针对已存在账号）：

```sh
docker compose exec myink-api myink set-role zlx admin
```

变更角色会撤销该账号旧会话，需要重新登录。降为普通用户时将最后一个参数改为 `user`。密码重设继续使用交互式 `myink reset-password`，不要把密码写入命令参数、源码或部署文件。

管理员的第二因子（TOTP）在账号页自行开启，默认关闭。认证器丢了或换手机后，服务器上的这条命令是唯一入口：

```sh
docker compose exec myink-api myink mfa-disable zlx
```

它清掉密钥并撤销该账号全部会话，之后凭密码即可登录；确认无误后再用账号页重新绑一个新认证器。没有恢复码，也不要为了绕过它去手工改库。机制细节见 [AUTH.md](AUTH.md) 的「管理员第二因子」。

容器启动使用 `myink init`：升级结构，但默认不建账号、不建示例书。只有确实需要开发示例数据时才手工运行 `myink init --seed`；不要在已有实际账号的库里用它补数据——它遇到缺失的 demo 账号会新建一个，而不是复用你现有的账号。

## 阅读指标

- 总览、用户与作品统计来自数据库聚合；列表分页，正文和节点详情按需读取。
- `cost_est` 是已记录的费用估算，不是供应商账单；缺少价格或历史费用的记录不能据此推断真实花费。
- 节点耗时来自已记录的 `duration_ms`；零值可能表示没有测量。任务创建至最后更新的时间跨度包含排队、暂停和人工等待，不能视为纯模型运行时间。
- 全部节点列表还包括没有任务编号的建书、整书大纲等调用，不能只看任务列表。
- 新的输入、输出、工具调用和召回快照有大小上限，并展示脱敏/截断标记；历史未保存的部分不能事后补造。脱敏识别常见凭据字段与格式，不承诺识别正文中任意形式的秘密。
- 记录会随使用增长，部署时仍需规划存储容量、留存和归档；本次不自动删除历史记录。
- 大小限制针对新增调试快照与管理接口响应；原流程后续还要读取的规划、审核等业务字段保持完整存储，不受新增快照限额覆盖，以免观测改变写作决策。

## 公网部署边界

当前管理查询复用 `ADMIN_DATABASE_URL`，在管理员鉴权后开启只读事务，普通连接和RLS规则不变。应用层只读事务不等于数据库凭据最小权限；公网加固应拆出专用只读报表角色，并完成 [公网检查清单](archive/PUBLIC-DEPLOYMENT-CHECKLIST.md)。增加管理面板不代表已经完成全部公网安全加固。

## 平台资源配置

管理员侧栏直接展开运营管理和 AI 资源管理；写作类内容统一由“写作资源”入口维护，不再单列提示词和题材包。页面内按类型筛选。`/admin/models` 展示模型卡片，`/admin/writing-resources` 统一展示写作资源卡片；旧提示词和题材包地址保留兼容。模型通过“新增模型”或“编辑”打开单模型表单，提示词和题材包直接点击卡片编辑。每次保存只更改当前资源，取消不保存；版本冲突保留当前草稿。旧 `/admin/configuration` 地址转到模型列表。模型分配和用户默认设置有各自的侧栏入口。

部署已配置完整 `PLATFORM_MODEL_*` 时，`myink init` 会把该内置服务一次性导入统一模型目录，密钥使用既有主密钥加密；模型卡片标记“平台内置”，可与自建连接一样编辑、控制用户可见及分配给各创作环节。导入保留已有默认路由和平台偏好，仅在没有写作默认时补上内置模型。管理员之后的修改以数据库配置为准，重复初始化不会覆盖编辑或复活已删除的模型；后续更换该模型密钥请在管理页编辑。

第一个启用的模型自动成为默认写作模型，可随后在“模型分配”调整。仍被任务角色引用的模型不能直接停用；删除默认写作模型且仍有其他模型时，须先选择一个已启用的替代模型。写作资源需要显式发布才能供用户选择，恢复历史内容通过版本回退完成。

「模型」中添加 OpenAI 兼容或 Anthropic 原生连接，填写显示名称、请求地址、真实模型 ID 和 API Key。管理员可拉取远端模型列表并测试连接。API Key 使用既有 `MODEL_CREDENTIAL_KEY` 加密存储，读取接口只返回是否已保存；编辑时留空保留原密钥。新连接必须填写密钥。请求地址沿用已有公网地址校验。

每个连接可独立控制启用和用户可见：启用但不公开的模型可作为后台规划、抽取、语义校验、审核和摘要模型；仅已启用且公开的模型出现在用户选择列表。至少为写作角色指定一个已启用的默认模型；未单独指定的规划、抽取、校验、审核和摘要角色沿用这个平台默认模型，也可分别覆盖。后台角色不会继承用户的写作选择。用户只选择写作和规划模型，不能改变后台连接或凭据。已下架、隐藏或删除的用户选择会失效，后续请求使用平台默认路由；不会恢复用户历史连接。

用户的「高级设置」默认折叠，主动展开后可选择公开的写作/规划模型，调整思考模式、任务预算和扫榜偏好。管理员在平台配置中统一维护默认思考、预算和扫榜值；个人缺少的字段实时继承平台默认，已有显式设置（包括 false 和 0）继续生效。恢复某一项平台默认只删除该字段的个人覆盖，其他偏好保留。已入队任务继续使用原预算快照。用户设置不再提供请求地址、密钥和探针。历史账号和作品中的模型连接不再参与路由，也不向客户端返回。原用户模型配置写接口会拒绝请求，避免仅通过隐藏界面绕过管理。

「提示词」和「题材包」入口统一进入写作资源管理，按参考资料、题材包、题材规则、文风、创作规则和表达规则显示卡片。点击卡片编辑专用字段；保存只更新草稿，发布前预览并确认。历史修订不可覆盖，管理员可以预览并回退到旧版本；回退产生新的发布事件，保留全部较新修订。 资源新增和编辑使用中文字段表单，无需手写 JSON。编辑页可确认“下架资源”：从用户可选目录移除，保留版本历史和已选作品快照。默认列表隐藏下架项，勾选“显示已下架资源”后可编辑并重新发布；下架不会保存尚未提交的编辑。

首次运行 `myink init` 时，只初始化缺失的内置资源：37 类真实题材、6 类精调规则、4 类文风、仓库内第三方参考资料、现有创作及表达规则；已有平台题材覆盖与角色追加规则在首次初始化时导入。再次初始化不会覆盖管理员已修改资源。来源与许可保留在资源中，输出解析、工具协议和权限约束继续由程序维护。

用户在作品「设置 → 本书写作资源」选择平台资源或个人资源，保存后持有正文及版本快照。平台新发布或回退不会自动改作品；工作台提示可用更新，用户选择采用或暂不更新。关闭提醒只针对当前发布事件去重，设置里仍可手动查看更新。采用更新检查作品修订和目标发布标识，冲突返回 409，重新检查后再确认。增删其他选择不会悄悄升级保留的平台条目。用户可明确设置主、辅题材；生成遵循 7:3 比例，辅题材不能覆盖主题材约束。个人覆盖不参与平台更新，用户文风样本、世界观、历史正文和复盘经验继续留在作品内。

个人资源与平台资源分表保存，复制或编辑只写入当前用户的资源库。平台管理接口不读取个人资源；普通用户不能写平台资源。写作资源接口使用统一 `/api/v1` 契约，管理请求记录审计，作品请求同时检查所有权及数据库 RLS，响应禁止缓存。

每个已受理任务把作品资源快照写入 Task.payload；运行、重试、恢复与子任务使用原快照。用户修改选择或管理员发布不影响运行中的任务。未配置资源的旧作品继续沿用原有链路；首次保存空选择表示主动关闭可选资源，不关闭输出格式和工具安全约束。

模型连接与平台默认偏好仍存于 `platform_configuration`，写作资源及不可变版本分别存储。升级运行既有 `myink init` 建表，不重写历史作品和任务。平台配置数据库不可用时请求会报错，不会绕过配置策略。

部署前仍需设置独立且稳定的 `MODEL_CREDENTIAL_KEY`，并保留备份；更换密钥将导致已保存连接无法解密。新增表由既有初始化流程与应用角色默认授权管理，不使用只读报表连接写入。


## 平台就绪检查与请求失败

管理配置页的「平台就绪状态」读取已保存配置，并可单独刷新；读取失败不会清除编辑草稿。接口 `GET /api/v1/admin/configuration/readiness` 仅管理员可用，经过审计且禁止缓存。它按六个角色检查有效路由、启用状态、模型 ID、支持的协议、地址格式和公网 IP 字面量、凭据解密及默认偏好校验；不返回地址、密钥或原始错误。不做 DNS 查询和供应商请求，保存与主动探针仍执行原有 DNS 地址守卫；「就绪」不保证实时网络或供应商凭据有效，需主动连接测试确认。

创作请求重新解析用户可见的 writer/planner 选择和平台后台角色路由。模型链创建、账号模型调用、初次入队、短篇确认建书以及续跑/计划确认都会检查所需配置；不可用时在账户成本预留、书籍额度、预算追加或入队之前返回通用 `503 PLATFORM_NOT_READY`。长篇任务检查六个角色，短篇全篇任务检查 writer/audit，短篇确认出方案检查 planner。已经受理的预算操作重复请求沿用回执，不重复追加或投递；已有任务的预算快照和断点继续保留。首次平台配置保存之前才允许使用部署环境的完整模型配置，保存空目录后不能绕过平台策略。

供应商调用沿用现有最多一次请求加三次重试。408、429、5xx 和传输故障保留有界退避；认证失败、其他永久 4xx、无效协议等配置错误立即停止，不新增另一层重试。流式失败继续清除已显示的片段，任务预算依旧逐次计量。普通用户遇到服务配置故障或免费额度限制时得到重试/联系管理员的提示。


### 管理员隔离测试环境

`docker compose --env-file /dev/null -f docker-compose.admin-test.yml up -d --wait`
创建独立的 `myink-admin-security-test` 项目。PostgreSQL、Redis、RabbitMQ 分别绑定本机
35432、36380、35673；PostgreSQL 数据保存在专属卷，和开发库、其他任务隔离。
不要同时运行两套使用该配置的测试。停止用 `down`，只有明确要清空测试库时才加 `--volumes`。

运行测试前显式设置以下环境变量（不要使用开发 `.env` 的连接串）：

```sh
export DATABASE_URL=postgresql+psycopg://myink_app:myink@127.0.0.1:35432/myink
export ADMIN_DATABASE_URL=postgresql+psycopg://myink:myink@127.0.0.1:35432/myink
export REDIS_URL=redis://127.0.0.1:36380/0 REDIS_ADDR=127.0.0.1:36380
export AMQP_URL=amqp://myink:myink@127.0.0.1:35673/
export APP_ENV=test EMBED_ENABLED=0 RANKINGS_ENABLED=0
export JWT_SECRET=test-jwt-secret-at-least-32-bytes-long
export PLATFORM_MODEL_API_KEY='' PLATFORM_MODEL_BASE_URL='' PLATFORM_MODEL_NAME=''
myink init --seed
python -m pytest tests/ -q
```

写作资源新增容量约束：单份正文 JSON（UTF-8）256 KiB、每份最多 80 个参考文件，
作品选择快照合计 2 MiB；资源写入请求流最多 8 MiB。参考工具索引最多 80 项且响应
不超过 12,000 字符，实际正文读取仍按 12,000 字符截断。超限写入不会保存。
`myink init` 会为旧作品资源快照补齐级联外键，只清理已不存在作品的孤立快照，保留有效作品。


### 写作提示词与界面用途

角色自动提示词、作者选用素材和作品自有内容已分区，完整阶段与生效说明见 [写作资源与生效时机](WRITING-RESOURCES.md)。角色创作要求及共用补充使用相同草稿/发布/回退机制，固定输出和工具规范保留。运营概览和数据分析展示真实按日趋势，费用单位为人民币。
