### A1 补充：修复要点

- 归属权威来源只能经 **任务 → 所属作品 → 用户** 判定，与既有 47 处端点的口径一致
- **禁止**采用任务载荷里的 `_gate_user_id` 作为归属依据——它是并发闸门的 Redis 键材料，非权威副本，无外键/约束，且仅在首次物化时写入
- 进度流入口（Go 侧）需在**建立连接之前**完成判定；连接建立后无法再干净拒绝
- 修复范围天然覆盖网关的两条别名路径（`/tasks/:task_id/*` 与 `/batches/:batch_id/*` 都落到同一批处理函数）

### A2 验证方法

续跑一个任务 → 等其终态 → 立刻对同一本书发起新生成任务 → 观察是否被拒（`CONCURRENCY_LIMIT`）。若被拒则该推断成立。
